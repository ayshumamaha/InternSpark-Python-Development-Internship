# Data Analysis Using Python Pandas

## 1. Project Overview

The Data Analysis project is a Python application that analyses a sample sales dataset using the Pandas library. It performs data cleaning, filtering, grouping, and statistical analysis to identify useful information from the dataset.

The project generates a sample sales dataset automatically and analyses product-wise sales, total revenue, average sales, and the best-selling product.

## 2. Objectives

- Develop a data analysis application using Python.
- Understand data manipulation using Pandas.
- Load and process data in CSV format.
- Perform data cleaning and filtering.
- Generate summary statistics and meaningful insights.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Library:** Pandas
- **Data Format:** CSV
- **Editor:** VS Code / Jupyter Notebook
- **Dataset:** Sample Sales Dataset

## 4. Features Implemented

- **Dataset Creation:** Creates a sample sales dataset.
- **Data Cleaning:** Removes duplicate records and handles missing values.
- **Summary Statistics:** Generates statistical information about the dataset.
- **Sales Analysis:** Calculates total and average sales.
- **Product-wise Analysis:** Groups sales and quantities by product.
- **Data Filtering:** Displays sales records above a specified amount.
- **Insights Generation:** Identifies the best-selling product and highest sales record.

## 5. Application Workflow

1. Start the Python application.
2. Create a sample sales dataset.
3. Save the dataset as a CSV file.
4. Load and clean the data using Pandas.
5. Generate summary statistics.
6. Perform product-wise grouping and filtering.
7. Display the analysis results and insights.

## 6. How to Run the Project

1. Install Python.
2. Install Pandas:

   `pip install pandas`

3. Save the code as `data_analysis.py`.
4. Run the program:

   `python data_analysis.py`

5. View the analysis results in the terminal.

## 7. Expected Output

The program displays the original and cleaned datasets, summary statistics, total sales, product-wise sales, product-wise quantities, and the best-selling product. It also generates a CSV file named `sales_data.csv`.

## 8. Conclusion

The Data Analysis project demonstrates how Python and Pandas can be used to clean, process, and analyse datasets. It provides practical experience in CSV handling, data manipulation, grouping, filtering, and statistical analysis. This project helps beginners understand how meaningful insights can be extracted from raw data.
