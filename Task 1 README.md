# Python Automation Script

## 1. Project Overview

The Python Automation Script is a simple application that automates basic file operations using Python. It helps users organize files by sorting them into folders, renaming files, and removing empty files.

The project uses Python's built-in modules to perform file operations automatically. It demonstrates automation, file handling, user input, and exception handling.

## 2. Objectives

- Develop a file automation program using Python.
- Understand file and directory handling.
- Automate file sorting and renaming operations.
- Remove unnecessary empty files.
- Practise using the OS module and exception handling.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Modules:** OS, Shutil, Logging
- **Editor:** VS Code / Python IDLE
- **Platform:** Windows

## 4. Features Implemented

- **File Sorting:** Organizes files into folders based on their extensions.
- **File Renaming:** Renames files automatically.
- **Empty File Cleaning:** Identifies and removes empty files.
- **Logging:** Records automation activities.
- **Exception Handling:** Handles file operation errors.

## 5. Application Workflow

1. Start the Python automation script.
2. Create a sample folder and files automatically.
3. Display the available automation options.
4. Select the required file operation.
5. Perform sorting, renaming, or cleaning.
6. Record activities in the log file.

## 6. How to Run the Project

1. Install Python.
2. Save the code as `automation.py`.
3. Run the program:

   `python automation.py`

4. Select an operation from the displayed menu.

## 7. Expected Output

The program automatically creates sample files and performs the selected file operations. Files are organized into folders, renamed, or cleaned based on the selected option. An activity log is also generated.

## 8. Conclusion

The Python Automation Script demonstrates how Python can automate routine file management tasks. It provides practical experience in file handling, directory management, logging, and exception handling. This project helps beginners understand the use of Python for everyday automation.
