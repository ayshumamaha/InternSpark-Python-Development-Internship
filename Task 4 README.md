# To-Do List Web Application

## 1. Project Overview

The To-Do List Web Application is a simple web-based application developed using Python and Flask. It allows users to add tasks, view their task list, and delete tasks when they are completed.

The application provides a basic and user-friendly interface through a web browser. It demonstrates Flask routing, handling form submissions, and managing data using Python lists.

## 2. Objectives

- Develop a simple To-Do List web application using Python Flask.
- Understand the basics of Flask web development.
- Implement routes to handle different user actions.
- Allow users to add and delete tasks.
- Display tasks dynamically on a webpage.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Framework:** Flask
- **Frontend:** HTML
- **Editor:** VS Code / Jupyter Notebook
- **Browser:** Google Chrome or any web browser

## 4. Features Implemented

- **Add Tasks:** Users can enter and add new tasks.
- **View Tasks:** Displays all added tasks on the webpage.
- **Delete Tasks:** Allows users to remove tasks from the list.
- **Simple Interface:** Provides an easy-to-use web interface.

## 5. Application Workflow

1. Start the Flask application.
2. Open the application in a web browser.
3. Enter a task in the input field.
4. Click the Add Task button.
5. View the added task on the webpage.
6. Click Delete to remove a task.

## 6. How to Run the Project

1. Install Python.
2. Install Flask using the command:

   `pip install flask`

3. Save the Python code as `todo_app.py`.
4. Run the application:

   `python todo_app.py`

5. Open the following URL in your browser:

   `http://127.0.0.1:5000`

## 7. Expected Output

The application displays a To-Do List webpage with an input field and an Add Task button. Users can add tasks, view them in a list, and delete tasks when required.

## 8. Conclusion

The To-Do List Web Application demonstrates the basic concepts of web development using Python Flask. It provides practical experience in creating web routes, handling user input, and dynamically displaying information on a webpage. This project helps beginners understand how Python can be used to develop simple web applications.
