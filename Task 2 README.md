# Weather API Integration Using Python

## 1. Project Overview

The Weather API Integration project is a Python application that retrieves real-time weather information using an external API. It allows users to enter a city name and view weather details such as temperature, humidity, and weather conditions.

The project uses the Requests module to communicate with a weather API and processes the returned JSON data to display the results.

## 2. Objectives

- Develop a weather information application using Python.
- Understand API integration and HTTP requests.
- Retrieve data from an external weather API.
- Parse and process JSON responses.
- Display weather information based on user input.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Module:** Requests
- **API:** Weather API
- **Data Format:** JSON
- **Editor:** VS Code / Python IDLE

## 4. Features Implemented

- **City Search:** Allows users to enter a city name.
- **Weather Information:** Retrieves current weather details.
- **Temperature Display:** Displays the temperature of the selected city.
- **Humidity Details:** Shows the humidity level.
- **Weather Conditions:** Displays the current weather description.
- **Error Handling:** Handles invalid city names and API errors.

## 5. Application Workflow

1. Start the Python application.
2. Enter the city name.
3. Send a request to the weather API.
4. Receive the API response in JSON format.
5. Extract the required weather information.
6. Display the results to the user.

## 6. How to Run the Project

1. Install Python.
2. Install the Requests module:

   `pip install requests`

3. Obtain an API key from a weather API provider if required.
4. Add the API key to the Python script.
5. Save the code as `weather.py`.
6. Run the program:

   `python weather.py`

7. Enter a city name to view its weather information.

## 7. Expected Output

The application displays the weather information for the entered city, including temperature, humidity, and weather conditions. It also displays an appropriate message if the city is invalid or the API request fails.

## 8. Conclusion

The Weather API Integration project demonstrates how Python applications can retrieve and process information from external APIs. It provides practical experience in HTTP requests, JSON data handling, user input, and exception handling. This project helps beginners understand how real-time data can be accessed using Python.
